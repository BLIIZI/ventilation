# Цифровой двойник системы вентиляции сварочного цеха

Сайт: https://bliizi.github.io/ventilation/

- `index.html` — 3D-двойник: две системы управления на одной смене;
- `calc.html` — книга Excel со всеми листами и формулами;
- `example.html` — пример расчёта для 3 постов с пояснениями;
- `model_raschet.xlsx` — сама книга.

Все страницы собираются из одного расчётного ядра (`publish.sh` в исходном проекте), поэтому числа на них совпадают.
